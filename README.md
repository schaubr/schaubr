# American Inno Canva Presentation Template

A professional 16:9 presentation template designed for **American Inno**, the digital media brand focused on local startups, technology, and innovation.

## 📁 What's Included

This repository contains everything you need to create stunning presentations in Canva:

1. **`canva-template-preview.html`** - Interactive visual preview of all slide layouts
2. **`canva-template-specification.md`** - Detailed design specifications and guidelines
3. **`README.md`** - This file

## 📊 Template Includes 10 Slide Layouts

1. **Title Slide** - Opening slide with gradient background
2. **Section Header** - Introduce new chapters/sections
3. **Content Slide - Text Heavy** - Bullet points and key information
4. **Image + Text** - Visual storytelling with supporting text
5. **Data/Statistics** - Showcase key metrics with stat cards
6. **Quote Slide** - Highlight testimonials or statements
7. **Two-Column Comparison** - Compare options or approaches
8. **Timeline** - Show progression and milestones
9. **Team/Contact** - Showcase team members
10. **Thank You/Closing** - End with call-to-action

## 📝 How to Create in Canva

### Step 1: Set Up Your Canvas
```
1. Go to Canva.com
2. Click "Create a design" → "Presentation (16:9)"
3. Canvas size: 1920 x 1080 px (automatic)
```

### Step 2: Add Brand Colors
```
1. Profile icon → "Brand Kit"
2. Add hex codes: #0A2463, #00B4D8, #0096C7, #FB5607, #E63946
```

### Step 3: Set Up Fonts
```
Headlines: Montserrat Bold (or Poppins Bold)
Body Text: Open Sans Regular (or Lato)
```

### Step 4: Build Each Slide
- Use the HTML preview as visual reference
- Follow layout specifications from the .md file
- Apply brand colors and typography consistently

### Step 5: Save as Template
- Make a copy for future presentations
- Customize content as needed

## 🎯 Design Principles

### Typography Scale
- Main Title: 72pt
- Section Headers: 48pt
- Subheadings: 36pt
- Body Text: 24pt
- Captions: 18pt

### Spacing
- Slide Margins: 40px
- Element Spacing: 24px
- Consistent padding throughout

### Visual Style
- Clean, modern, tech-focused
- Bold typography with clear hierarchy
- Strategic use of gradients
- Rounded corners (12px) for images
- Subtle shadows for depth

## 💡 Usage Tips

### Do's ✓
- Use white space generously
- Maintain consistent spacing
- Keep text hierarchy clear
- Use high-quality images (1920x1080px minimum)
- Limit each slide to one main idea
- Use brand colors consistently

### Don'ts ✗
- Don't overcrowd slides
- Don't mix more than 2 brand colors per slide
- Don't use low-resolution images
- Don't center-align body text
- Don't exceed 6 bullet points per slide
- Don't use overly complex animations

## 🎭 When to Use Each Slide Type

- **Title Slide**: Opening presentation
- **Section Header**: Starting new topics/chapters
- **Content - Text**: Explaining concepts, listing features
- **Image + Text**: Case studies, examples, visual stories
- **Statistics**: Quarterly reports, performance metrics, key numbers
- **Quote**: Testimonials, customer feedback, thought leadership
- **Comparison**: Before/after, pros/cons, option analysis
- **Timeline**: Roadmaps, project phases, historical progression
- **Team**: About us, contact info, team introduction
- **Thank You**: Closing, Q&A, contact call-to-action
