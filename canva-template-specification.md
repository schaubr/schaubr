# American Inno Presentation Template - Canva Specification
## 16:9 Format (1920 x 1080 px)

Based on American Inno's position as a tech/startup news media brand focused on innovation and entrepreneurship.

---

## Brand Color Palette

### Primary Colors
- **Deep Blue**: #0A2463 (Primary brand color - trust, technology)
- **Bright Teal**: #00B4D8 (Secondary - innovation, energy)
- **Electric Blue**: #0096C7 (Accent - modern, digital)

### Accent Colors
- **Coral Orange**: #FB5607 (Call-to-action, highlights)
- **Vibrant Red**: #E63946 (Emphasis, urgency)

### Neutral Colors
- **White**: #FFFFFF (Background, text on dark)
- **Light Gray**: #F8F9FA (Alternative background)
- **Medium Gray**: #6C757D (Supporting text)
- **Dark Gray**: #212529 (Body text)

---

## Typography

### Fonts (Canva alternatives)
- **Headlines**: Montserrat Bold / Poppins Bold (900 weight)
- **Subheadings**: Montserrat SemiBold / Poppins SemiBold (600 weight)
- **Body Text**: Open Sans / Lato Regular (400 weight)
- **Accent/Stats**: Roboto Bold / Inter Bold (700 weight)

### Type Scale
- **Main Title**: 72pt
- **Section Headers**: 48pt
- **Subheadings**: 36pt
- **Body Text**: 24pt
- **Captions/Small Text**: 18pt

## Design Elements & Components

### Icons
- Style: Line icons (2px stroke weight)
- Color: Bright Teal (#00B4D8) or Coral Orange (#FB5607)
- Size: 48px for emphasis, 32px for supporting elements

### Shapes & Decorative Elements
- **Accent Lines**: 4-8px solid, use brand colors
- **Boxes/Cards**: 8-12px border-radius, subtle shadow (0 4px 12px rgba(0,0,0,0.1))
- **Geometric Shapes**: Circles, rectangles with rounded corners
- **Gradient Overlays**: Use sparingly, Deep Blue to Electric Blue

### Image Treatments
- **Corner Radius**: 12px for consistency
- **Shadows**: Subtle drop shadow for depth
- **Borders**: Optional 4px border in brand colors
- **Filters**: Slight desaturation (90%) for consistency

### Data Visualization
- **Charts**: Use brand color palette
  - Primary data: Deep Blue (#0A2463)
  - Secondary data: Bright Teal (#00B4D8)
  - Highlights: Coral Orange (#FB5607)
- **Graphs**: Clean, minimal gridlines
- **Icons for Stats**: Modern, line-style icons

## Animation Suggestions (Canva Pro)

### Entrance Animations
- **Title Slides**: Fade + Slide Up
- **Content**: Wipe or Rise
- **Stats/Numbers**: Pop or Count Up
- **Images**: Fade or Pan

### Transition Recommendations
- **Between Sections**: Dissolve or Push
- **Content Slides**: Fade
- **Duration**: 0.5-0.8 seconds

## Brand Voice & Tone

When creating content for these slides:
- **Professional yet Approachable**: Tech-savvy but not overly technical
- **Innovation-Focused**: Emphasize growth, disruption, entrepreneurship
- **Data-Driven**: Use statistics and metrics when possible
- **Action-Oriented**: Clear CTAs and next steps
- **Community-Focused**: Highlight local ecosystems and connections

## Template Usage Guidelines

### Do's:
✓ Use white space generously - don't overcrowd slides
✓ Maintain consistent spacing (40px margins, 24px between elements)
✓ Keep text hierarchy clear using the type scale
✓ Use high-quality images (minimum 1920x1080px)
✓ Limit each slide to one main idea
✓ Use brand colors consistently

### Don'ts:
✗ Don't use more than 3 font sizes per slide
✗ Don't mix more than 2 brand colors per slide (plus neutrals)
✗ Don't use low-resolution images
✗ Don't center-align body text (left-align for readability)
✗ Don't use overly complex animations
✗ Don't exceed 6 bullet points per slide

## Canva Implementation Steps

1. **Create New Presentation**:
   - Go to Canva.com
   - Click "Create a design"
   - Select "Presentation (16:9)"
   - Size: 1920 x 1080 px

2. **Set Up Brand Kit** (Canva Pro feature):
   - Go to Brand Kit
   - Add colors from palette above
   - Upload logo (if available)
   - Set brand fonts

3. **Create Master Slides**:
   - Create each of the 10 slide layouts above
   - Use Elements > Shapes for backgrounds and accent elements
   - Use Text tool with specified fonts and sizes
   - Add placeholder images using Elements > Photos

4. **Apply Styling**:
   - Set backgrounds with gradients or solid colors
   - Add accent bars and decorative elements
   - Configure text styles for consistency
   - Add page numbers using Text tool

5. **Test & Refine**:
   - View in presentation mode
   - Check readability from distance
   - Ensure consistency across all slides
   - Export as PDF for review
