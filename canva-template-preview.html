How to Use This Template in Canva

Step 1: Create Your Presentation

  1. Go to Canva.com and sign in
  2. Click "Create a design" → Select "Presentation (16:9)"
  3. Your canvas size will be automatically set to 1920 x 1080 px

Step 2: Set Up Brand Colors

  1. Click on your profile icon → "Brand Kit" (Canva Pro feature)
  2. Add these hex codes to your brand palette:
    • #0A2463 (Deep Blue - Primary)
    • #00B4D8 (Bright Teal - Secondary)
    • #0096C7 (Electric Blue - Accent)
    • #FB5607 (Coral Orange - Highlight)
    • #E63946 (Vibrant Red - Emphasis)

Step 3: Set Up Typography

  1. In Canva, search for these fonts:
    • Headlines: Montserrat Bold (or Poppins Bold)
    • Body Text: Open Sans Regular (or Lato)
  2. Add them to your Brand Kit for quick access

Step 4: Create Each Slide

Use the visual examples above as reference. For each slide:

  1. Add a new slide in Canva
  2. Set the background color or gradient (use the gradient tool for title/thank you slides)
  3. Add text boxes with the specified font sizes and colors
  4. Use Elements → Shapes for accent bars, circles, and decorative elements
  5. Add placeholders for images using Elements → Photos
  6. Apply 12px rounded corners to images (click image → Edit image → Round corners)

Step 5: Create Reusable Elements

  • Logo: Add "INNO" text or your own logo in top-left of slides
  • Page Numbers: Add text box in bottom-right corner
  • Accent Lines: Use line tool with specified px widths
  • Bullet Points: Use custom bullets by adding small circles (Elements → Shapes)

Step 6: Save as Template

  1. Once all slides are created, click "File" → "Make a copy"
  2. Save this as your master template
  3. For each new presentation, make a copy and customize the content

Pro Tips:

  • Consistency: Use 40px margins on all slides for uniform spacing
  • Alignment: Use Canva's alignment guides (View → Show rulers & guides)
  • Transitions: Keep it simple - use "Fade" or "Dissolve" (0.5-0.8 seconds)
  • Images: Use high-quality photos (Canva has great stock photos, search "tech startup" or "innovation")
  • Export: Download as PDF for sharing, or as PNG for individual slides

Additional Resources:

  • Full detailed specifications: See canva-template-specification.md
  • For icons: Search "tech icons line" or "business icons" in Canva Elements
  • For charts: Use Canva's chart tool and customize with brand colors
